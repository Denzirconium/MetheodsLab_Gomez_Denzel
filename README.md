# Methods Lab

**Author:** Zhel  
**Language:** Java

## About the Project

This project contains different Java activities that helped me practice using methods and understand how they work. It includes basic calculations, checking numbers, working with arrays, and using recursion.

## Tasks Included

1. Greeting Method
2. Arithmetic Operations
3. Factorial
4. Sum of Array Elements
5. Prime Number Checker
6. Finding the Largest Array Element
7. GCD and LCM

**Challenges:**
- Recursive Factorial
- Fibonacci Sequence
- Palindrome Checker

1. Open `MethodsLab.java` in NetBeans.
2. Run the program.
3. Enter the required inputs.
4. Check the results in the output console.
